## How I Approach Problems

When something does not work, I prefer to isolate the issue layer by layer:

```text
Client
  ↓
Network
  ↓
DNS
  ↓
Ports / sockets
  ↓
Service
  ↓
Logs
  ↓
Configuration
```

I try to understand the actual cause of a problem instead of only applying a temporary workaround.
